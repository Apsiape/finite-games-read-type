Finite checks for the games and spectral prices

Run verify_hashes.py before changing or executing a pristine distribution.
Copy this entire directory and run run_checks.py on the copy to regenerate
outputs. The runner fails on nonzero exit and enforces one CPU and a working
set below one decimal gigabyte. Python, NumPy, SciPy, SymPy and psutil are
required. Recorded outputs include timings and therefore change on rerun.

critical/: the nine-copy game, exact KMS probabilities, and finite shadows.
states/: fixed-state constructions, exact integer capacity and graph checks.
third/: exact conference-game predicates and every ideal probability.
prices/: endpoint formulas, Airy/Gaussian diagnostics and profile counterexamples.
robust/: permutative converse, sequential instruments and measure estimates.

ratios/: six explicit full predicates, ordered rational basis certificates,
every exact event probability, nonorthogonal witnesses and closure checks.
The exact arithmetic uses rational coefficients of squarefree radicals.
Each checker raises on failure; optimization mode is rejected by checkers
that use assertions. The runner rejects every nonzero child exit.

phase/: matrix rank/dilation-defect remainder and sorted-profile diagnostics,
sine-template coefficients, exact tail arithmetic, composition truth tables,
and the 16 settled / 8 open type-cost cells. These finite checks do not prove
the hosting, complexity or exponent-realization imports.

Exact algebra is distinguished from floating-point diagnostics in the paper.
These checks concern finite predicates and abstract spectral resource formulas.
They compute no observer-energy bound, cosmological loss floor, or physical
admissible-state restriction.
No finite computation proves the arbitrary-algebra classification imports.
